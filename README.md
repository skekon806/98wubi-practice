# 五笔98 练习工具

基于 98 版五笔的纯前端练习工具，覆盖 3500 常用字。无需服务器、无需安装，双击 `index.html` 即可使用。

## 功能

- **常用字练习**：按频率拆为常用前500、常用中500、常用后500 三档，看汉字输全码，错题显示码元拆解图
- **简码练习**：一级（25 字）、二级（611 字）、三级（668 字）简码
- **码元练习**：259 个码元图，看码元输所在键位
- **艾宾浩斯复习**：每字答对后按 2组→5组→10组→20组→40组→80组 间隔复现，越拉越长；答错重置为 2组。答对的新字也进入复习，新字练完后自动进入复习阶段
- **进度保存**：每个模式独立存档（localStorage），下次打开可继续
- **全键盘操作**：自动跳格、退格回退、末格输入完自动检查；答错必须照正确编码重打一遍才能继续
- **汉堡菜单**：左上角切换五种训练模式

## 使用方法

直接双击打开 `index.html` 即可，数据通过 `<script src>` 从同目录加载，无跨域问题。

| 按键 | 作用 |
| --- | --- |
| 字母键 | 输入编码，自动跳到下一格 |
| 退格 | 回退修改 |
| 最后一格输入完 | 自动检查对错 |

答错时会显示正确编码（二级/三级简码及编码练习附全码对照和拆字图），需照着重新输入正确编码才能进入下一题。

## 文件结构

```
wubi98/
├── index.html          # 主页面（双击打开）
├── app.js              # 练习引擎（界面逻辑、复习算法、进度保存）
├── 98WB-0.otf          # 码元字体（渲染拆分字符，88KB）
└── data/               # 练习数据（JS 格式）
    ├── decomp.js       #   码元拆解字典：字 → 拆解序列（由 98.txt 生成）
    ├── code.js         #   全码字典：字 → 全码（由 98_2.txt 生成）
    ├── encode1.js      #   常用前500：1500 常用字高频段
    ├── encode2.js      #   常用中500：1500 常用字中频段
    ├── encode3.js      #   常用后500：1500 常用字低频段
    ├── jm1.js          #   一级简码：25 字
    ├── jm2.js          #   二级简码：611 字
    ├── jm3.js          #   三级简码：668 字
    └── root.js         #   码元练习：286 个码元
```

## 数据说明

- 每字拆解由 `data/decomp.js` 字典统一提供（`window.WUBI_DECOMP`，运行时按字查询）
- 每字全码由 `data/code.js` 字典统一提供（`window.WUBI_CODE`，运行时按字查询）
- 各模式数据文件（encode*/jm*）只存 `{v 字, a 答案编码}`，不再内嵌拆解与全码
- 码元拆解数据来源：[aardio/wubi-lex 的 98.txt](https://github.com/aardio/wubi-lex/blob/master/sepllingData/98.txt)（27535 字拆解表）
- 全码表来源：[yanhuacuo/98wubi-tables](https://github.com/yanhuacuo/98wubi-tables)（按 98.txt 字集过滤）
- 码元练习的码元字符 → 键位映射，由 3500 字拆解与编码逐位对应统计而来（无冲突）
- 数据均为自用学习整理，98 五笔编码无版权问题

## 技术细节

- 纯 HTML/CSS/JS，零依赖
- 数据以 `window.WUBI_DATA['模式key']` 挂到全局，新增模式只需在 `data/` 加一个文件并在 `app.js` 的 `MODES` 里加一项
- 复习算法：每字（含首答对的新字）答完后按 2组→5组→10组→20组→40组→80组 间隔排期，到期优先复现；复习答错重置为 2组；新字队列练完自动进入复习阶段，复习答完即清档
