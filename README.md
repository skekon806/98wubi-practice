# 五笔练习工具（86 / 98 / 新世纪）

纯前端五笔练习工具，覆盖**码元与常用字编码**，支持 **86 版 / 98 版 / 新世纪（06）** 三个版本一键切换。无需服务器、无需安装，双击 `index.html` 即可使用，也可部署到 GitHub Pages。

## 功能

- **五笔版本切换**：练习区底部可切换 86 / 98 / 新世纪，答案与拆解随版本实时变化，进度按版本独立保存
- **码元练习**：看码元输所在键位，答错显示键名与区域；码元数量按版本区分（98=260 / 86=215 / 06=223）
- **一级简码练习**：25 个高频字，看汉字输对应单键
- **常用字练习**：按频率分常用前500 / 常用中500 / 常用后500 三档，看汉字用**输入法直接打字**，工具校验打出的字是否正确；答错显示正确字、简码（若有）、全码与码元拆解
- **反查**：顶部「反查」视图，输入一个或多个汉字，左侧显示该字、右侧实时反查三版（86/98/新世纪）的全码与码元拆解
- **拼音反查**：切到「按拼音」，输入 `zhang` / `zhang3` / `lv4`，按声调列出常用字及当前版本五笔编码；点字可回到汉字反查看拆解
- **码元编号表**：`root.html` 展示各版本码元编号（如 A1、B2）
- **艾宾浩斯复习**：错题直接回炉：答错 5 题后回来，答对后按 5题→20题→50题 间隔递增，间隔满即完成
- **进度保存**：每个模式独立存档（localStorage），下次打开可继续
- **全键盘操作**：自动跳格、退格回退、末格输入完自动检查；答错须照正确编码重打一遍才能继续
- **移动端适配**：窄屏自动全宽布局，输入框适配触屏

## 使用方法

直接打开 `index.html` 即可，数据通过 `<script src>` 从同目录加载，无跨域问题。

常用字练习：显示一个汉字，用**本机输入法**在输入框中打出这个字，按回车（或空格）确认。打对了自动进入下一题；打错了会显示正确字与编码，照着重新打。

码元练习：看码元输所在键位，单键输入，输完自动判对。

答错后输入框自动清空，直接从输入法重新打即可。

查看码元编号表请打开 `root.html`。

反查视图可切换「按汉字 / 按拼音」，并选择 86 / 98 / 新世纪编码版本。拼音模式支持数字声调（`1`-`4`，轻声不写数字，如 `zhang3`）、`ü` 用 `v`（如 `lv4`），也兼容 `zhāng` 这类带声调符号的输入。

## 数据架构

练习数据与查询字典分离，版本数据统一挂在 `VERSIONS` 配置下（`app.js`）：

- **查询字典** `data/dict_86.js` / `dict_98.js` / `dict_06.js` → `window.WUBI_DICT_86/98/06`：字 → `{s 码元拆解, c 全码}`，反查与答案推导均按当前版本查询
- **简码** `data/jm1.js`（一简，三版通用）、`jm2_98.js` / `jm2_86.js` / `jm2_06.js`（二简）、`jm3_98.js` / `jm3_86.js` / `jm3_06.js`（三简）：练习反馈时显示对应字的简码
- **码元** `data/root_98.js` / `root_86.js` / `root_06.js`：`{v 码元字形, a 键位}`
- **拼音索引** `data/pinyin.js` → `window.WUBI_DATA['pinyin']`：无声调拼音 → `[显示用拼音, 声调, 汉字串]`，多音字会出现在多个读音下；由 `tools/build_pinyin.py` 生成
- **反查逻辑** `js/lookup.js`：汉字反查与拼音反查的 UI 渲染，在 `app.js` 之前加载
- 码元与拆解字形以 Unicode PUA 码位（U+E000 区段）存储，通过 `wubi-root.ttf` 字体渲染，无需图片

## 技术细节

- 纯 HTML/CSS/JS，零依赖
- 版本资源集中在 `app.js` 顶部的 `VERSIONS` 配置：每个版本自带 `dict` / `root` 一套数据，切换版本即切换整套数据源；新增数据只需在配置里填字段
- 拆解/全码通过 `getSplit()` / `getFull()` 按当前版本字典查询，模式数据无需内嵌
- 复习算法：卡片答完按 5→20→50 题间隔回炉到学习队列，答对递增、答错重置 5 题；间隔满即完成，队列清空即结束
- 反查视图基于三版字典实时查询渲染；拼音模式基于 `data/pinyin.js` 的静态索引，输入归一化后按声调分组，不依赖网络
- 反查逻辑在 `js/lookup.js`，练习引擎在 `app.js`；均为传统 `<script>`，保持双击打开可用

## 数据来源与致谢

### 常用字数量

- 1988《现代汉语常用字表》：常用字 2500 + 次常用字 1000 = **3500 字**（覆盖率 99.48%）
- 2013《通用规范汉字表》：一级字表（常用字集）**3500 字**；一级 + 二级为 6500 字；全表 8105 字
- 因此没有官方的“5000 常用字”档，本工具按一级字表的 **3500 字** 做拼音反查

参考：[教育部答记者问](http://www.moe.gov.cn/jyb_xwfb/s271/202009/t20200915_488073.html)、[1988 年联合通知](https://cdn035.yun-img.com/static/upload/tsszpt/team/20230122100436_72944.pdf)
