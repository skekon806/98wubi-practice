# 五笔练习工具（86 / 98 / 新世纪）

纯前端五笔练习工具，覆盖**码元、简码与常用字编码**，支持 **86 版 / 98 版 / 新世纪（06）** 三个版本一键切换。无需服务器、无需安装，双击 `index.html` 即可使用，也可部署到 GitHub Pages。

## 功能

- **五笔版本切换**：练习区底部可切换 86 / 98 / 新世纪，答案与拆解随版本实时变化，进度按版本独立保存
- **码元练习**：看码元输所在键位，答错显示键名与区域；码元数量按版本区分（98=260 / 86=215 / 06=223）
- **简码练习**：一级简码三版通用（25 字 · 单键）；二级简码随版本切换（98=613 / 86=606 / 06=608 字 · 两键）
- **常用字练习**：按频率分常用前500 / 常用中500 / 常用后500 三档，看汉字输编码——有简码用简码（一级优先，其次二级、三级），无简码用全码，答错显示简码+全码对照与码元拆解
- **反查**：顶部「反查」视图，输入一个或多个汉字，左侧显示该字、右侧实时反查三版（86/98/新世纪）的全码、简码与码元拆解
- **码元编号表**：`root.html` 展示各版本码元编号（如 A1、B2）
- **艾宾浩斯复习**：错题直接回炉：答错 5 题后回来，答对后按 5题→20题→50题 间隔递增，间隔满即完成
- **进度保存**：每个模式独立存档（localStorage），下次打开可继续
- **全键盘操作**：自动跳格、退格回退、末格输入完自动检查；答错须照正确编码重打一遍才能继续
- **移动端适配**：窄屏自动全宽布局，输入框适配触屏

## 使用方法

直接打开 `index.html` 即可，数据通过 `<script src>` 从同目录加载，无跨域问题。

| 按键 | 作用 |
| --- | --- |
| 字母键 | 输入编码，自动跳到下一格 |
| 退格 | 回退修改 |
| 最后一格输入完 | 自动检查对错 |

答错时会显示正确编码、全码对照与码元拆解，需照着重新输入正确编码才能进入下一题。

查看码元编号表请打开 `root.html`。

## 数据架构

练习数据与查询字典分离，版本数据统一挂在 `VERSIONS` 配置下（`app.js`）：

- **查询字典** `data/dict_86.js` / `dict_98.js` / `dict_06.js` → `window.WUBI_DICT_86/98/06`：字 → `{s 码元拆解, c 全码}`，反查与答案推导均按当前版本查询
- **一级简码** `data/jm1.js`：三版通用，存 `{v 字, a 答案编码}`
- **二级简码** `data/jm2_98.js` / `jm2_86.js` / `jm2_06.js`：纯文本字串，答案由对应版本全码前 2 位推导
- **三级简码** `data/jm3_98.js` / `jm3_86.js` / `jm3_06.js`：纯文本字串，答案由全码前 3 位推导
- **码元** `data/root_98.js` / `root_86.js` / `root_06.js`：`{v 码元字形, a 键位}`
- 码元与拆解字形以 Unicode PUA 码位（U+E000 区段）存储，通过 `wubi-root.ttf` 字体渲染，无需图片

## 技术细节

- 纯 HTML/CSS/JS，零依赖
- 版本资源集中在 `app.js` 顶部的 `VERSIONS` 配置：每个版本自带 `dict` / `jm1` / `jm2` / `jm3` / `root` 一套数据，切换版本即切换整套数据源；新增数据只需在配置里填字段
- 拆解/全码通过 `getSplit()` / `getFull()` 按当前版本字典查询，模式数据无需内嵌
- 复习算法：卡片答完按 5→20→50 题间隔回炉到学习队列，答对递增、答错重置 5 题；间隔满即完成，队列清空即结束
- 反查视图基于三版字典实时查询渲染，简码按版本分别查询
