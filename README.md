# 五笔98 练习工具

基于 98 版五笔的纯前端练习工具，覆盖 3500 常用字。无需服务器、无需安装，双击 `index.html` 即可使用。

## 功能

- **编码练习**：1500 个常用字，看汉字输全码，错题显示字根拆解图
- **简码练习**：一级（25 字）、二级（611 字）、三级（668 字）简码
- **字根练习**：259 个字根图，看字根输所在键位
- **艾宾浩斯复习**：错题按 2组→5组→10组→20组→40组 间隔复现，越拉越长，不会反复重复同一批
- **进度保存**：每个模式独立存档（localStorage），下次打开可继续
- **全键盘操作**：自动跳格、退格回退、末格输入完自动检查；答错必须照正确编码重打一遍才能继续
- **汉堡菜单**：左上角切换五种训练模式

## 使用方法

直接双击打开 `index.html` 即可，数据通过 `<script src>` 从同目录加载，无跨域问题。

| 按键 | 作用 |
| --- | --- |
| 字母键 | 输入编码，自动跳到下一格 |
| 退格 | 回退修改 |
| 最后一格输入完 | 自动检查对错 |

答错时会显示正确编码（二级/三级简码及编码练习附全码对照和拆字图），需照着重新输入正确编码才能进入下一题。

## 文件结构

```
wubi98/
├── index.html          # 主页面（双击打开）
├── app.js              # 练习引擎（界面逻辑、复习算法、进度保存）
├── 98WB-0.otf          # 字根字体（渲染拆分字符，88KB）
└── data/               # 练习数据（JS 格式），每模式一个文件
    ├── encode.js       #   编码练习：1500 常用字
    ├── jm1.js          #   一级简码：25 字
    ├── jm2.js          #   二级简码：611 字
    ├── jm3.js          #   三级简码：668 字
    └── root.js         #   字根练习：286 个字根
```

## 数据说明

- 3500 常用字的字根拆解以**字根字符**存储（Unicode PUA 码位），通过 `98WB-0.otf` 字体渲染，无需图片
- 字根练习的字根字符 → 键位映射，由 3500 字拆解与编码逐位对应统计而来（无冲突）
- 字根拆分数据来源：五笔小筑《常用三千五百字》表格
- 简码全码对照表来源：[yanhuacuo/98wubi-tables](https://github.com/yanhuacuo/98wubi-tables)（27533 字全码表）
- 数据均为自用学习整理，98 五笔编码无版权问题

## 技术细节

- 纯 HTML/CSS/JS，零依赖
- 数据以 `window.WUBI_DATA['模式key']` 挂到全局，新增模式只需在 `data/` 加一个文件并在 `app.js` 的 `MODES` 里加一项
- 复习算法：答错即入复习队列，间隔按题数递增；答对的新卡不进入复习
