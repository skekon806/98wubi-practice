# 五笔98 练习工具

基于 98 版五笔的纯前端练习工具，覆盖码元、简码与常用字编码。无需服务器、无需安装，双击 `index.html` 即可使用，也可部署到 GitHub Pages。

## 功能

- **码元练习**：258 个码元，看码元输所在键位，答错显示键名与区域
- **简码练习**：一级（25 字 · 单键）、二级（613 字 · 两键）
- **常用字练习**：按频率分常用前500 / 常用中500 / 常用后500 三档，看汉字输编码——有简码用简码（一级优先，其次二级、三级），无简码用全码，答错显示简码+全码对照与码元拆解
- **反查**：顶部「反查」视图，输入一个或多个汉字，实时反查全码、简码与码元拆解
- **艾宾浩斯复习**：错题直接回炉：答错 5 题后回来，答对后按 5题→20题→50题 间隔递增，间隔满即完成
- **进度保存**：每个模式独立存档（localStorage），下次打开可继续
- **全键盘操作**：自动跳格、退格回退、末格输入完自动检查；答错须照正确编码重打一遍才能继续
- **移动端适配**：窄屏自动全宽布局，输入框适配触屏

## 使用方法

直接打开 `index.html` 即可，数据通过 `<script src>` 从同目录加载，无跨域问题。

| 按键 | 作用 |
| --- | --- |
| 字母键 | 输入编码，自动跳到下一格 |
| 退格 | 回退修改 |
| 最后一格输入完 | 自动检查对错 |

答错时会显示正确编码、全码对照与码元拆解，需照着重新输入正确编码才能进入下一题。

## 数据架构

练习数据与查询字典分离：

- **练习数据** `data/*.js`：jm1、root 存 `{v 字, a 答案编码}`；jm2、jm3、encode1~3 只存**纯文本字串**，答案由全码推导（二级=全码前2、三级=前3、常用字一/二/三级简码优先）
- **查询字典** `data/dict.js` → `window.WUBI_DICT`：字 → `{s 码元拆解, c 全码}`，运行时按字查询
- 码元字符以 Unicode PUA 码位存储，通过 `98WB-0.otf` 字体渲染，无需图片

## 文件结构

```
wubi98/
├── index.html      # 主页面（双击打开）
├── app.js          # 练习引擎（界面、复习算法、反查、进度保存）
├── 98WB-0.otf      # 码元字体（渲染拆解字符，88KB）
└── data/           # 练习数据（JS 格式）
    ├── dict.js     #   查询字典：字 → 拆解 + 全码（27535 字）
    ├── encode1.js  #   常用前500
    ├── encode2.js  #   常用中500
    ├── encode3.js  #   常用后500
    ├── jm1.js      #   一级简码：25 字
    ├── jm2.js      #   二级简码：613 字
    ├── jm3.js      #   三级简码数据：3995 字（取自7000常用字，供常用字答案与反查）
    └── root.js     #   码元练习：258 个码元
```

## 技术细节

- 纯 HTML/CSS/JS，零依赖
- 数据以 `window.WUBI_DATA['模式key']` 挂到全局，新增模式只需在 `data/` 加一个文件并在 `app.js` 的 `MODES` 里加一项
- 拆解/全码通过 `getSplit()` / `getFull()` 从 `WUBI_DICT` 查询，模式数据无需内嵌
- 复习算法：卡片答完按 5→20→50 题间隔回炉到学习队列，答对递增、答错重置 5 题；间隔满即完成，队列清空即结束
- 反查视图基于 `WUBI_DICT` 实时查询渲染

## 已知缺漏

对照码元图片集，`root.js` 中 E、I 两键各缺 1 个码元（98wubi-tables项目数据遗漏，暂无法补充）：

- **E 键**：缺「月」形码元（「背」字下半部以「月」为码元）
- **I 键**：缺「水」形码元（「求」字下部、以「泰」字底部的字形代替）
